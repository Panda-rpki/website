About

RPKI validation, built for research and deployment.

Panda-RPKI is a Relying Party implementation designed to retrieve RPKI repository data, validate RPKI objects, and produce validated data for routing systems and other applications.

The project is being developed as open-source software. We welcome feedback, bug reports, interoperability testing, and contributions from the RPKI and routing-security community.

Features

Core capabilities

Repository Retrieval

Retrieve RPKI repository data using supported synchronization mechanisms.

Object Validation

Validate RPKI certificates and signed objects according to relevant standards.

Validated Output

Produce validated RPKI data for routing systems, experiments, and operational tooling.

Research Friendly

Designed to support protocol experiments, measurements, interoperability work, and reproducible testing.

Project status

Active development and testing

Panda-RPKI is currently in an early testing stage and is not yet recommended for production deployment. The current implementation may contain bugs, incomplete features, or unexpected behavior.

If you identify a potential issue, protocol-compliance problem, or interoperability issue, please open a GitHub issue. Contributions and pull requests are welcome.
